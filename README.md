# 🚀 JavaScript e TypeScript do básico ao avançado (Full Stack)

Este repositório contém todos os exercícios, projetos e anotações que desenvolvi durante o curso de **JavaScript e TypeScript** do instrutor Luiz Otávio Miranda na Udemy. O foco é dominar as tecnologias mais modernas do ecossistema JS/TS, abrangendo desde a lógica de programação até arquiteturas complexas.

## 🎓 Sobre o Curso
O treinamento é um guia completo de Full Stack que cobre:
*   **JavaScript Moderno:** ES6+, Promises, Async/Await e Classes.
*   **TypeScript:** Tipagem estática, Generics, Decorators e Namespaces.
*   **Back-end:** Node.js, Express, SQL (MySQL/PostgreSQL) e NoSQL (MongoDB).
*   **Front-end:** React.js, Hooks, Redux e Next.js.
*   **Arquitetura:** Programação Orientada a Objetos (POO), Programação Funcional e Design Patterns.
